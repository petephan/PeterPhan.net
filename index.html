CalSnap

iOS & Android app · Expo, React Native, TypeScript, Supabase · 2026

Vibe coded with Claude Code: I directed the product and Claude wrote the code, so it wasn't hand-coded.

Snap a photo of a meal and get calories and macros back in seconds. A vision model identifies each food, estimates portions and returns structured nutrition data, validated on the server and again in the app.

  • Personalised daily targets from the Mifflin-St Jeor equation, with the reasoning shown to the user.
  • Supabase auth and Postgres with row-level security, plus an offline-first copy that retries failed saves.
  • The AI key never ships in the app: the analysis server requires sign-in, rate-limits scans and validates uploads by file signature.
  • Streaks, milestone badges and reminders that skip meals already logged.

Screens use a seeded demo account and public-domain/CC0 sample meal photos.
